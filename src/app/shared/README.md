# Shared

Reusable, presentational building blocks with no feature-specific logic:

- `ui/` — design-system components (AppButton, AppCard, AppBadge, ...)
- `directives/`
- `pipes/`
- `models/` — TypeScript interfaces (portfolio data contract)
- `utils/` — pure helper functions

Anything here must be feature-agnostic and safe to reuse anywhere.
